# CodeRun — решения на Java

Мои решения задач с [CodeRun](https://coderun.yandex.ru). Репозиторий учебный:
цель — вспомнить Java и алгоритмы, а не собрать коллекцию ответов.

## Правила этого репозитория

- **Условия задач не копируются дословно.** В `task.md` — только моя краткая
  формулировка своими словами и ссылка на оригинал. Текст задачи принадлежит Яндексу.
- **Решения активных соревнований не публикуются** до их окончания — это прямой
  запрет в правилах сезонов CodeRun. Сюда попадают только задачи из тренировочного каталога.

## Структура

```
src/tasks/t01_example/
    Main.java     — решение (package tasks.t01_example;)
    task.md       — своя формулировка + ссылка + разбор подхода
    samples/      — in1.txt / out1.txt из примеров
```

Имя папки = имя Java-пакета: латиница, цифры и `_`, но **не начинается с цифры**
(отсюда префикс `t`) и без дефисов.

## Как запускать

Из корня репозитория:

```bash
javac -d out src/tasks/t01_example/Main.java && java -cp out tasks.t01_example.Main < src/tasks/t01_example/samples/in1.txt
```

В IntelliJ: пометить `src` как Sources Root, дальше зелёная стрелка у каждого `main`.
